# مرجع نسخة Android المرفقة

المرجع الذي حدده المالك: `ALBAYDA-COURT-v1.2.zip`، وهو APK مجمع باسم `ai.teable.albayda.court.preview` وإصدار `1.2-test` (versionCode 3)، وليس أرشيف مشروع Java أو صفحات ويب.

تأكدت المطابقة الثنائية لكل من `classes.dex` و`assets/android.js` مع الملفات الأصلية الموجودة في المستودع قبل التعديل. أعيد بناء مصدر Android من هذا المرجع، مع تصحيح صيغ Java المستعادة كي تصبح قابلة للبناء.

الخصائص المحفوظة:

- `CredentialVault` وتشفير AES/GCM عبر Android Keystore.
- حفظ الدخول على الهاتف، والفتح بالبصمة، ودعم FingerprintManager للأجهزة الأقدم.
- جسر WebMessagePort المقيد بعنوان الخادم الموثوق، مع سكربت `android.js` الأصلي.
- اختيار الملفات، وحفظ التنزيلات، والطباعة، وإعادة المحاولة، واستعادة حالة WebView ووضع ملء الشاشة.
- الحزمة الأصلية وAndroid 6 فأحدث. الإصدار المصحح `1.3.0` (versionCode 4).

التعديلات:

- إزالة الاعتماد على رابط معاينة منتهي وإضافة إعداد خادم HTTPS من داخل التطبيق أو وقت البناء.
- تقييد الثقة بالمخطط والمضيف والمنفذ، ومنع المحتوى المختلط.
- إظهار أخطاء HTTP من 400 فأعلى.
- أيقونة الشعار بخلفية شفافة دون طبقة خلفية ملونة.
- تصحيح معالجة فشل حفظ البيانات المشفرة بعد استعادة مصدر Java.
- دعم واجهة تسجيل الدخول لخدمات الحفظ والبصمة الأصلية.

الأرشيف المرفق لا يتضمن صفحات الواجهة الأصلية؛ كان يحملها من خادم معاينة خارجي يعيد 404 وقت المراجعة. صفحات الويب في المشروع مبنية وفق عقود Python الموجودة وليست واجهة قديمة مستخرجة من APK.

نجح بناء المصدر المستعاد ونجحت اختبارات خدمات Python والمتصفح. لم تُجر تجربة بصمة فعلية على هاتف. APK المرفق للتجربة موقّع بمفتاح بناء محلي، ويختلف عن توقيع النسخة الأصلية؛ لا يمكن اعتماده تحديثًا مباشرًا للنسخة المثبتة دون مفتاح التوقيع الأصلي. لا تحذف بيانات التطبيق القديم بغرض التثبيت قبل حفظ ما تحتاجه. إصدار المتجر يتطلب توقيعًا إنتاجيًا معتمدًا من المالك.
